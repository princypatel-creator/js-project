# ✨Local Storage

A simple web application that demonstrates how to store, retrieve, update, and delete data using the browser's `localStorage` API.This project demonstrates the implementation of the Browser Local Storage API using HTML, CSS, and JavaScript. Users can store, retrieve, update, and delete data directly in the browser without requiring any backend or database. The stored data remains available even after refreshing or reopening the browser, showcasing the power of client-side storage in modern web applications.

## Features

* Save data in browser local storage
* Retrieve stored data instantly
* Update existing records
* Delete specific or all stored data
* Persistent data even after page refresh

## Technologies Used

* HTML
* CSS
* JavaScript
* Browser Local Storage API
